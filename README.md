## 2. Prerequisites
- Node.js 22.x
- NPM 10.9.4 node packages manager
- Code Editor (VSC)
- Git

## 3. Quick Start
1. Clone the repository

    git clone <https://github.com/travelandrepeatdev/travelandrepeat-fe.git>

    cd travelandrepeat-fe
2. Install dependencies
    
    npm i
3. Verify the build

    npm run build
4. Run it locally

    npm run dev
